# Samyak's Portfolio

My personal portfolio website, built with HTML and CSS and hosted on GitHub Pages.

Live site: https://samyakghaju.github.io/Portfolio/

## About the project

This started as a plain semantic HTML page. In Week 3 I added an external stylesheet (`style.css`), made the layout responsive with Flexbox and Grid, and published it with GitHub Pages.

## Files

- `index.html` - the page content
- `style.css` - all the styling
- `assets/` - images and other files
- `README.md` - this file, plus my weekly progress

## Run it locally

```
git clone https://github.com/samyakghaju/Portfolio.git
```

Then open `index.html` in your browser.
